# Dataset

This project uses the publicly available **Underwater Object Detection Dataset** associated with the paper:

**"Underwater Species Detection using Channel Sharpening Attention"**

The dataset provides annotations in **MS COCO format**.

## Source

The original dataset repository is available here:

https://github.com/LehiChiang/Underwater-object-detection-dataset

## Dataset Usage

The dataset was used to train and evaluate an underwater object detection model built with TensorFlow/Keras.

The dataset contains three object classes used in this project.

## Annotation Format

Annotations are provided in the **MS COCO JSON format**.

The dataset includes information such as:

* Images
* Bounding-box annotations
* Object categories
* Image IDs
* Annotation IDs
